**一个 HTML 文件就是全部**：双击打开就能用，发给家人也能用。
不联网、无账号、不用安装，数据只存在你自己电脑的浏览器里，改一个字就自动保存一次。

## ✨ 它能帮你做什么

- **像填表格一样录家人** — 点「＋」加人、双击改名字、拖动卡片调长幼次序，
  拖到别人名下就是过继；做错了 Ctrl+Z 随时撤销
- **手机 / iPad 也顺手** — 触摸拖动调长幼、长按卡片呼出菜单、双击改名、
  双指捏合缩放；屏幕变窄自动精简界面
- **给家人配上照片** — 「人员档案」里点「添加照片」，卡片立刻显示圆形头像，点头像看大图；
  「文件 ▾ → 导入照片文件夹…」按文件名一次配好全家的照片，备份可连原图一起带走，
  导出图片 / PDF 也带着头像
- **版式配色，点了就换** — 「查看 ▾ → 视觉设置…」把样式集中在一处：排列方向四选
  （从上到下 / 从下到上 / 从左到右 / 从右到左），配色三选（羊皮纸 / 晴空 / 暗色），
  横排 / 谱书竖排即点即换，不用刷新
- **滚轮直接缩放、拖空白平移** — 像看地图一样顺手；不习惯可在视觉设置里关掉，
  改回滚轮滚动页面、Ctrl＋滚轮才缩放
- **世祖按世系排，字辈另起序** — 真实始祖从 1 世开始，子女比父母加 1 世，谱名容器不计世数；
  无字辈也显示世数，名字不改变编号。贴入字辈表，再在视觉设置中填「字辈从第几世开始」：
  填 10 时，1–9 世只显示世数，10 世起用诗的第 1 字、11 世第 2 字；世祖与辈序分开显示
- **打印出来是一本老谱的样子** — 竖排文字、世代成行、五代一张表，导出 PDF 直接送打印店装订成册；
  谱名、堂号、源流、始祖记都自动印在谱前
- **整树一页，放大还能搜名字** — 「文件 ▾ → 导出 PDF」默认单页矢量：文字、连线、形状放大仍清晰，
  文字可搜索；也可选 A4 横向分页打印。主菜单按当前折叠状态导出，右键「导出此支…」则包含全部后代
- **Markdown 也能导回来** — 「文件 ▾ → 导出 Markdown（可导回）」生成可读的谱序、字辈和成员信息，
  从「恢复备份」可导回本工具格式的 `.md`；完整备份请用含照片原图的 JSON
- **配偶写法跟着老谱走（可选）** — 视觉设置里可开启「丁嘉」→「丁氏嘉」，
  默认关（现代姓名不加「氏」）；配 / 继配 / 嗣子 / 嗣出 / 兼祧 / 止，老谱的体例这里都有
- **数据只在你自己手里** — 不联网、无账号、不上传任何服务器；
  一键导出备份文件，换电脑或传给亲戚，双击导入就回来
- **几十年后也打得开** — 不依赖任何软件和服务：一个 HTML 文件，U 盘里存一份就能传给下一代

## 🚀 快速开始

**方式〇（最快）**：直接打开在线版 → **[https://zaxchou.github.io/zupu/](https://zaxchou.github.io/zupu/)**

**方式一（本地使用，推荐）**：到 [Releases](https://github.com/zaxchou/zupu/releases) 按语言下载——
简体 `index.html` / 繁體 `index-zh-Hant.html` / English `index-en.html` / 日本語 `index-ja.html`，
一个文件就是全部，下载双击即用。首次使用会弹出向导：

- **先看看示例** — 内置明朝皇室世系演示谱（朱元璋家族，真实历史，世祖按父子关系编号，字辈另列）
- **从空白开始** — 填上你的谱名（如「李氏族谱」）和堂号，从第一代建起
- **导入之前的备份** — 已有本工具导出的 json，直接恢复

**方式二**：`git clone` 本仓库后双击 `index.html`。

录入自己家族：双击名字改名、点「＋」添加成员、「文件 ▾ → 谱序…」设置谱名 / 堂号 /
字辈表 / 源流——全部改成你家的。`samples/` 里有真实家族的使用示例可以导入参考。

## ❓ 常见问题

**数据存在哪里？会不会丢？**
族谱数据存在本机浏览器的 localStorage，照片原图存在本机 IndexedDB，不上传任何服务器。
定期用「文件 ▾ → 备份（含照片原图）」导出 JSON 完整备份；普通「备份到文件」只含照片缩略图。
换电脑用「恢复备份」导入。本次用户数据结构不变，原有 JSON 备份继续可用。

**世祖和字辈怎么分别设置？旧设置会怎样？**
世祖只按父子关系排列：真实始祖为 1 世，子女比父母加 1 世，谱名容器不计世数。
没有字辈表也会显示世数，名字是否含字辈字都不改变编号。
在「查看 ▾ → 视觉设置…」填写「字辈从第几世开始」，例如字辈表为「高 瞻 祁 见 祐」、起用世数为 10：
1–9 世只显示世祖，辈序留空；10 世显示「10 世」和「辈序 1 · 高」，11 世显示「11 世」和「辈序 2 · 瞻」。
世祖和辈序是两个独立标记。旧本机 `genBase` 设置迁移为字辈起用世数，不再平移世祖；
设置仍存在本浏览器，不改用户 tree 结构，不新增 JSON 或 Markdown schema。

**PDF 能放大、搜索吗？报缺字 U+28EE7（𨻧）怎么办？**
导出弹窗始终默认单页矢量，即使是大谱也不自动预选分页；A4 横向分页由你自行选择。
常用字使用 Apache-2.0 的 DroidSansFallbackFull，另有独立 SIL OFL 1.1 的 ZupuRareSupport 后备字体
（约 16 KB，包含 𨻧、𠮷、𡊨、𠀀），补上 U+28EE7。两款字体分别内嵌所用字形子集，
保留原 Unicode 真文字，可搜索、保持矢量、离线查看；连线与形状也保持矢量。照片仍是图片，清晰度取决于原图。
其他缺字可在「生僻字与其他文字」选择含所需字形、允许合法嵌入的本机 TTF；
它可以只补缺字，常用字仍有默认字体后备，不必由一份 TTF 涵盖整张谱。自选字体仅用于本次单页导出，不上传、不保存到族谱。
所有可用字体都没有对应字形时仍明确报错；不保证覆盖全 Unicode 或整个扩展 B 区。
分页是连续切片：跨页边的卡片会在相邻两页各显示一部分，拼接后完整。单页 PDF 的横向排版可整名搜索；竖排为逐字排印，整名搜索可能只命中单字。
小红书小工具不支持保存 PDF，包内剥离两款 PDF 字体与后端，但包含新的世祖与字辈编号规则。

**Markdown 能代替完整备份吗？**
本工具导出的 `.md` 可从「恢复备份」导回；这不是任意 Markdown 文本、所有字段都无损的承诺。
Markdown 不含照片和折叠状态，完整备份请用「备份（含照片原图）」导出的 JSON。

**支持多人协作 / 在线同步吗？**
不支持，这是刻意的设计选择：族谱数据私密且低频编辑，本地单文件是最稳妥的形态。
多人协作请共享备份 json，各自导入修改后再合并。

**界面文字 / 字辈 / 谱名都是别人家的？**
示例而已——谱序里全部可改，字辈表粘贴你自己家族的字辈即可。

**浏览器数据清了会怎样？**
所以请备份。`data.json` 是仓库内置的示例快照；你自己的备份在你手里。
