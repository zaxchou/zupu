**HTML ファイル 1 つがすべて**：ダブルクリックで開けば、そのまま使えます。
家族に送っても使えます。ネットもアカウントもインストールも不要。データは自分の
ブラウザの中だけにあり、編集は自動で保存されます。

**譜書縦書き（古法）**は伝統的な族譜の体裁を再現：世代ごとに行をまとめ、名を縦書き
（右→左）、行の左に世代を表示——印刷 / PDF 出力すればそのまま**製本できます**。

## ✨ できること

- **フォームのように家族を入力** — 「＋」で追加、ダブルクリックで改名、カードを
  ドラッグして兄弟の順序を変更。別のカードに重ねれば養縁。Ctrl+Z でいつでも元に戻る
- **スマホ / タブレットも快適** — ドラッグで順序変更、長押しでメニュー、
  ダブルタップで改名、ピンチで拡大縮小。画面が狭いと表示を自動調整
- **家族に写真を** — 「人物情報」で「写真を追加」すると、カードに丸いアバターが付いて
  クリックで拡大。「ファイル ▾ → 写真フォルダを取り込む…」ならファイル名で自動照合して
  一括設定。バックアップにオリジナルを添付することもでき、書き出した画像 / PDF にも
  アバターが入ります
- **見た目はワンクリックで切替** — 「表示 ▾ → 表示設定…」にまとまっています：配置方向4種
  （上から下 / 下から上 / 左から右 / 右から左）、配色3種（羊皮紙 / 晴空 / ダーク）、
  横書き / 譜書縦書きも、クリックしたその場で反映。再読み込み不要
- **スクロールで拡大縮小、ドラッグで移動** — ホイールでそのままズーム、空白をつかんで
  ドラッグで移動と、地図アプリ感覚。従来式のほうがよければ表示設定でオフにできます
  （ホイールは画面のスクロール、Ctrl＋スクロールで拡大縮小）
- **名前を書けば世代を自動判定** — 字輩表（例：明皇室の字輩詩「高瞻祁见祐」）を貼れば、各メンバーの
  世代を自動表示。譜書の世代数（廿三世など）とも基準合わせできます。v15.46 では祖先の世代数が
  切り詰められる問題を修正。基準が 10 なら、その前の三世代は 7、8、9、続いて 10、11、12 と表示します
- **印刷すれば本物の譜書の体裁** — 縦書き、世代ごとの行、五世一表。PDF で書き出して
  そのまま印刷店へ製本。譜名・堂号・始祖記も自動で前に印刷
- **ツリー全体を検索できる 1 ページに** — ファイルメニューの PDF 出力は単一ページのベクター PDF が
  既定です。文字・接続線・図形は拡大しても鮮明で、文字検索も可能。印刷には A4 横向きのページ分割を
  選べます。通常の出力は現在の折りたたみ状態に従い、メンバーのメニューから枝を出力すると全子孫を含みます
- **Markdown を再取り込み** — 「ファイル ▾ → Markdown を出力（再取り込み可）」で譜序・字輩・
  メンバー情報を読みやすいテキストに。このツールの形式の `.md` は「バックアップ復元」から取り込めます。
  完全なバックアップには写真のオリジナルを含む JSON を使ってください
- **配偶者の呼称も譜書どおり** — 配 / 継配 / 嗣子 / 嗣出 / 兼祧 / 止、古典の体例を網羅
- **データは自分の手の中** — オフライン、アカウント不要、アップロード一切なし。
  ワンクリックで json バックアップ、親族との共有もダブルクリックで復元
- **数十年後も開ける** — ソフトもサービスにも依存しない：USB メモリ 1 本がそのまま家宝に

## 🚀 はじめ方

**方法 0（最速）**：オンライン版を開く → **[https://zaxchou.github.io/zupu/](https://zaxchou.github.io/zupu/)**
（UI は中国語。日本語は Release の `index-ja.html` を）

**方法 1（ローカル、推奨）**：[Releases](https://github.com/zaxchou/zupu/releases) から
言語に合ったファイル 1 つをダウンロード（日本語：`index-ja.html`。中文 `index.html` /
繁體中文 `index-zh-Hant.html` / English `index-en.html` も可）、ダブルクリック。初回はウィザードが出ます：

- **まずデモを見る** — 明皇室の実在系譜（朱元璋家、字輩詩で自動世代判定）
- **白紙から始める** — 譜名を入れて第一世代から作成
- **以前のバックアップから復元** — このツールが書き出した json を読み込む

**方法 2**：`git clone` して `index-ja.html` をダブルクリック。

自分の家族を記録する：名前をダブルクリックで変更、「＋」でメンバー追加、
「ファイル ▾ → 譜序…」で譜名 / 字輩表 / 系統を設定——すべて自分の家のものに。

## ❓ よくある質問

**データはどこに保存される？消えない？**
家系図データはこのブラウザの localStorage、写真のオリジナルはローカルの IndexedDB に保存します。
サーバーには送信しません。完全なバックアップにはファイルメニューで写真のオリジナルを含む JSON を
保存してください。通常のバックアップには写真のサムネイルのみが入り、別の PC では「バックアップ復元」で
取り込めます。今回もユーザーデータの構造は変わらず、既存の JSON バックアップを使えます。

**PDF は拡大・検索できる？表示できない文字は？**
既定の単一ページモードは DroidSansFallbackFull TrueType フォントの使用字形だけを埋め込みます。
文字は検索でき、接続線と図形はベクターのままです。写真は画像のため、鮮明さは元の画像に依存します。
PDF ダイアログでは、必要な字形を持ち、埋め込みが許可されたローカルの TTF を選べます。
この単一ページ出力にだけ使用し、アップロードや家系図への保存は行いません。字形が不足すると明確なエラーを
表示します。内蔵・指定フォントとも Unicode 全体への対応は保証しません。A4 横向きのページ分割印刷も
引き続き選べ、v15.46 では座標変換（CTM）による切り抜きの不具合を修正しました。ページ分割は連続したスライスで、ページ境界にまたがるカードは隣り合う 2 ページに分かれて表示され、貼り合わせると完全になります。単一ページ PDF の横書きは氏名全体で検索できますが、縦書きは 1 文字ずつ配置するため、氏名全体の検索は 1 文字ずつしか一致しない場合があります。
小紅書（Xiaohongshu）小工具は PDF 保存に対応しないため、パッケージからフォントと PDF バックエンドを
除きますが、今回の世代表示の修正は含みます。

**Markdown は完全なバックアップになる？**
このツールが出力した `.md` は「バックアップ復元」で再取り込みできます。任意の Markdown テキストの
全項目を損失なく復元できるという保証ではありません。写真と折りたたみ状態は含まれないため、
完全なバックアップには写真のオリジナルを含む JSON を使ってください。

**共同編集 / オンライン同期は？**
対応しません。これは意図した設計です：家系図データは私密性が高く編集頻度は低い。
ローカルのシングルファイルが最も堅実な形です。共同編集はバックアップ json を
やり取りして各自で取り込んでください。

**デモの名前は他人のものでは？**
ただのサンプルです——譜序ですべて変更でき、字輩表も自分の家のものを貼り付けるだけ。

**ブラウザデータを消したら？**
だからこそバックアップを。リポジトリの `data.json` はサンプルスナップショット、
自分のバックアップは自分の手の中に。
