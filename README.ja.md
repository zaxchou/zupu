**HTML ファイル 1 つがすべて**：ダブルクリックで開き、家系図を作り始められます。
ネット接続もアカウントもサーバーも不要。データは自分のブラウザの中だけに保存され、
編集は自動で保存されます。日本語版は `index-ja.html`。

**譜書縦書き（古法）**は伝統的な族譜の体裁を再現：世代ごとに行をまとめ、名を縦書き
（右→左）、行の左に世代を表示——印刷 / PDF 出力すればそのまま**製本できます**。

## ✨ 機能

- **2 つの表示** — 通常ツリー / 譜書縦書き（古法）。印刷は現在の表示に追従
- **編集機能** — 追加 / 削除 / 名前変更 / 人物情報（性別、嗣子・嗣出・兼祧、字・号、止）、
  ドラッグで並べ替え、ドラッグで養縁（ループ防止）、元に戻す / やり直し
- **字輩による世代判定** — 字輩表を定義すれば、名前から各メンバーの世代を自動推定。
  譜書の世代数との基準合わせにも対応
- **譜序** — 譜名、堂号、系統、始祖記、家族の由緒。出力に自動で添付
- **配偶者の譜式** — 譜書式表示、人ごとの呼称（配 / 継配 / 娶 / 聘 / 側室）
- **出力** — PNG / PDF / **世系録（欧式・五世一表）** / Markdown / 製本印刷
- **自動保存** — 編集は即保存（ブラウザ内）。json バックアップで機種変更も簡単
- **3 つの言語** — 中文 / English / 日本語。データモデルは共通で、バックアップは互換

## 🚀 はじめ方

**方法 0（最速）**：オンライン版を開く → **[https://zaxchou.github.io/zupu/](https://zaxchou.github.io/zupu/)**
（UI は中国語。日本語は Release の `index-ja.html` を）

**方法 1（ローカル、推奨）**：[Releases](https://github.com/zaxchou/zupu/releases) から
言語に合ったファイル 1 つをダウンロード（日本語：`index-ja.html`。中文 `index.html` /
English `index-en.html` も可）、ダブルクリック。初回はウィザードが出ます：

- **まずデモを見る** — 自由にいじれるサンプル家系図
- **白紙から始める** — 譜名を入れて第一世代から作成
- **バックアップから復元** — このツールが書き出した json を読み込む

**方法 2**：`git clone` して `index-ja.html` をダブルクリック。

自分の家族を記録する：名前をダブルクリックで変更、「＋」でメンバー追加、
「表示 ▾ → 譜序」で譜名 / 字輩表 / 系統を設定——すべて自分の家のものに。

## ❓ よくある質問

**データはどこに保存される？消えない？**
この PC のこのブラウザ（localStorage）に保存されます。サーバーへの送信は一切ありません。
「ファイル ▾ → バックアップ保存」で json を定期バックアップし、「バックアップ復元」で
どの環境でも復元できます。

**共同編集 / オンライン同期は？**
対応しません。これは意図した設計です：家系図データは私密性が高く編集頻度は低い。
ローカルのシングルファイルが最も堅実な形です。共同編集はバックアップ json を
やり取りして各自で取り込んでください。

**デモの名前は他人のものでは？**
ただのサンプルです——譜序ですべて変更でき、字輩表も自分の家のものを貼り付けるだけ。

**ブラウザデータを消したら？**
だからこそバックアップを。リポジトリの `data.json` はサンプルスナップショット、
自分のバックアップは自分の手の中に。
