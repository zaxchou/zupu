**一個 HTML 檔案就是全部**：雙擊開啟就能用，傳給家人也能用。
不連線、無帳號、免安裝，資料只存在你自己電腦的瀏覽器裡，改一個字就自動儲存一次。
本檔案為繁體中文版：`index-zh-Hant.html`。

## ✨ 它能幫你做什麼

- **像填表格一樣錄家人** — 點「＋」加人、雙擊改名、拖動卡片調長幼次序，
  拖到別人名下就是過繼；做錯了 Ctrl+Z 隨時復原
- **手機 / iPad 也順手** — 觸控拖動調長幼、長按卡片呼出選單、雙擊改名、
  雙指捏合縮放；螢幕變窄自動精簡介面
- **為家人配上照片** — 「人員檔案」裡點「新增照片」，卡片立刻顯示圓形頭像，點頭像看大圖；
  「檔案 ▾ → 匯入照片資料夾…」按檔名一次配好全家的照片，備份可連原圖一起帶走，
  匯出圖片 / PDF 也帶著頭像
- **版式配色，點了就換** — 「檢視 ▾ → 視覺設定…」把樣式集中在一處：排列方向四選
  （從上到下 / 從下到上 / 從左到右 / 從右到左），配色三選（羊皮紙 / 晴空 / 暗色），
  橫排 / 譜書豎排即點即換，不用重新整理
- **滾輪直接縮放、拖空白平移** — 像看地圖一樣順手；不習慣可在視覺設定裡關掉，
  改回滾輪捲動頁面、Ctrl＋滾輪才縮放
- **世祖按世系排，字輩另起序** — 真實始祖從 1 世開始，子女比父母加 1 世，譜名容器不計世數；
  無字輩也顯示世數，名字不改變編號。貼上字輩表，再於視覺設定中填「字輩從第幾世開始」：
  填 10 時，1–9 世只顯示世數，10 世起用詩的第 1 字、11 世第 2 字；世祖與輩序分開顯示
- **列印出來是一本老譜的樣子** — 豎排文字、世代成行、五代一張表，匯出 PDF 直接送印刷廠裝訂成冊；
  譜名、堂號、源流、始祖記都自動印在譜前
- **整樹一頁，放大還能搜尋名字** — 「檔案 ▾ → 匯出 PDF」預設單頁向量：文字、連線、形狀放大仍清晰，
  文字可搜尋；也可選 A4 橫向分頁列印。主選單按目前摺疊狀態匯出，右鍵「匯出此支…」則包含全部後代
- **Markdown 也能匯回來** — 「檔案 ▾ → 匯出 Markdown（可導回）」產生可讀的譜序、字輩和成員資訊，
  從「恢復備份」可匯回本工具格式的 `.md`；完整備份請用含照片原圖的 JSON
- **配偶寫法跟著老譜走** — 「丁嘉」顯示成「丁氏嘉」；
  配 / 繼配 / 嗣子 / 嗣出 / 兼祧 / 止，老譜的體例這裡都有
- **資料只在你自己手裡** — 不連線、無帳號、不上傳任何伺服器；
  一鍵匯出備份檔，換電腦或傳給親戚，雙擊匯入就回來
- **幾十年後也打得開** — 不依賴任何軟體和服務：一個 HTML 檔案，隨身碟存一份就能傳給下一代

## 🚀 快速開始

**方式〇（最快）**：直接開啟線上版 → **[https://zaxchou.github.io/zupu/](https://zaxchou.github.io/zupu/)**
（線上版為簡體介面；繁體請下載 `index-zh-Hant.html`）

**方式一（本機使用，推薦）**：到 [Releases](https://github.com/zaxchou/zupu/releases) 按語言下載——
繁體 `index-zh-Hant.html` / 簡體 `index.html` / English `index-en.html` / 日本語 `index-ja.html`，
一個檔案就是全部，下載雙擊即用。首次使用會彈出精靈：

- **先看看示例** — 內建明朝皇室世系演示譜（朱元璋家族，真實歷史，世祖按親子關係編號，字輩另列）
- **從空白開始** — 填上你的譜名（如「陳氏族譜」）和堂號，從第一代建起
- **匯入之前的備份** — 已有本工具匯出的 json，直接還原

**方式二**：`git clone` 本倉庫後雙擊 `index-zh-Hant.html`。

錄入自己家族：雙擊名字改名、點「＋」新增成員、「檔案 ▾ → 譜序…」設定譜名 / 堂號 /
字輩表 / 源流——全部改成你家的。

## ❓ 常見問題

**資料存在哪裡？會不會丟？**
族譜資料存在本機瀏覽器的 localStorage，照片原圖存在本機 IndexedDB，不上傳任何伺服器。
定期用「檔案 ▾ → 備份（含照片原圖）」匯出 JSON 完整備份；一般「備份到檔案」只含照片縮圖。
換電腦用「恢復備份」匯入。本次使用者資料結構不變，原有 JSON 備份繼續可用。

**世祖和字輩怎麼分別設定？舊設定會怎樣？**
世祖只按親子關係排列：真實始祖為 1 世，子女比父母加 1 世，譜名容器不計世數。
沒有字輩表也會顯示世數，名字是否含字輩字都不改變編號。
在「檢視 ▾ → 視覺設定…」填寫「字輩從第幾世開始」，例如字輩表為「高 瞻 祁 見 祐」、起用世數為 10：
1–9 世只顯示世祖，輩序留空；10 世顯示「10 世」和「輩序 1 · 高」，11 世顯示「11 世」和「輩序 2 · 瞻」。
世祖和輩序是兩個獨立標記。舊本機 `genBase` 設定遷移為字輩起用世數，不再平移世祖；
設定仍存在本瀏覽器，不改使用者 tree 結構，不新增 JSON 或 Markdown schema。

**PDF 能放大、搜尋嗎？報缺字 U+28EE7（𨻧）怎麼辦？**
匯出彈窗始終預設單頁向量，即使是大譜也不自動預選分頁；A4 橫向分頁由你自行選擇。
常用字使用 Apache-2.0 的 DroidSansFallbackFull，另有獨立 SIL OFL 1.1 的 ZupuRareSupport 後備字型
（約 16 KB，包含 𨻧、𠮷、𡊨、𠀀），補上 U+28EE7。兩款字型分別內嵌所用字形子集，
保留原 Unicode 真文字，可搜尋、保持向量、離線檢視；連線與形狀也保持向量。照片仍是圖片，清晰度取決於原圖。
其他缺字可在「生僻字與其他文字」選擇含所需字形、允許合法嵌入的本機 TTF；
它可以只補缺字，常用字仍有預設字型後備，不必由一份 TTF 涵蓋整張譜。自選字型僅用於本次單頁匯出，不上傳、不儲存到族譜。
所有可用字型都沒有對應字形時仍明確報錯；不保證涵蓋全 Unicode 或整個擴展 B 區。
分頁是連續切片：跨頁邊的卡片會在相鄰兩頁各顯示一部分，拼接後完整。單頁 PDF 的橫向排版可整名搜尋；直排為逐字排印，整名搜尋可能只命中單字。
小紅書小工具不支援儲存 PDF，套件內移除兩款 PDF 字型與後端，但包含新的世祖與字輩編號規則。

**Markdown 能代替完整備份嗎？**
本工具匯出的 `.md` 可從「恢復備份」匯回；這不是任意 Markdown 文字、所有欄位都無損的承諾。
Markdown 不含照片和摺疊狀態，完整備份請用「備份（含照片原圖）」匯出的 JSON。

**支援多人協作 / 線上同步嗎？**
不支援，這是刻意的設計選擇：族譜資料私密且低頻編輯，本機單檔案是最穩妥的形態。
多人協作請共享備份 json，各自匯入修改後再合併。

**介面文字 / 字輩 / 譜名都是別人家的？**
示例而已——譜序裡全部可改，字輩表貼上你自己家族的字輩即可。

**瀏覽器資料清了會怎樣？**
所以請備份。`data.json` 是倉庫內建的示例快照；你自己的備份在你手裡。
